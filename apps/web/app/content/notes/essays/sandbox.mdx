这个网站不是作品集，是一个 **sandbox**：想学什么技术，就在这里搭一个真能用的小东西。

现在的骨架：

- **`@shiqi/pixel`**：不依赖任何框架的像素绘图库：调色板、可复现的随机数、抖动、图标、壁纸和涂鸦生成器。
- **`@shiqi/ui`**：组件库。所有主题（白天、夜晚、1984 金、抹茶）都是 CSS 变量，组件只读语义变量，所以加一个主题只要加一组变量。可以在 [组件库页面](/ui) 看到全部组件。
- **`apps/web`**：React Router 服务端渲染。页面先以 HTML 到达，再变成可交互的 React。
- **服务器**：一台云主机上的 k3s，网站和 Redis 都是 k8s 里的服务，HTTPS 证书自动续签。

接下来想做的：

1. **课程笔记**：每门课一个目录，MDX 写，里面可以直接嵌 [小测验](/notes/standards)。
2. **在线 quiz**：题库放 Redis，记录答题情况，做间隔重复。
3. **API**：`/api/*` 已经留好位置，先从 `/api/health` 开始。
4. **Kafka**：等更大的机器到位，用它做事件流，比如统计每个玩具被玩了多少次（匿名的）。

慢慢来，每一步都做成能上线的样子。
