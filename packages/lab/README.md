# @shiqi/lab

The frame around a lab: toolbar (play, step, speed, rewind), guided scenario
player and menu, story panel, event list, tabbed panels, forms with an admin
guard, and the glossary. Each lab passes its own (translated) words; defaults are
in `LAB_STRINGS`. Import `@shiqi/lab/styles.css` once, after `@shiqi/ui`'s.
