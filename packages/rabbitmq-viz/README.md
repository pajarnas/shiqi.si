# @shiqi/rabbitmq-viz

React views over `@shiqi/rabbitmq`: `RabbitLab` (stage, inspector, panels,
terminal, events) and ten guided stories in `scenarios.ts`. Text is in
`RABBIT_STRINGS` (`@shiqi/rabbitmq-viz/strings`); wrap the lab in
`RabbitStringsProvider` to translate it. Import `@shiqi/rabbitmq-viz/styles.css`
after `@shiqi/ui` and `@shiqi/lab` styles.
